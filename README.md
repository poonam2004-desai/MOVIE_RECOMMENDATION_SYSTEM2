## 📦 Installation & Setup

### Prerequisites
- Python 3.8 or higher
- pip (Python package manager)
- Git

### Step-by-Step Installation

**1. Clone the Repository**
```bash
git clone https://github.com/poonam2004-desai/Movie_Recommendation_System.git
cd Movie_Recommendation_System
```

**2. Create Virtual Environment (Optional but Recommended)**
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

**3. Install Dependencies**
```bash
pip install -r requirements.txt
pip install python-dotenv
```

**4. Setup Environment Variables**
```bash
# Create .env file
cp .env.example .env

# Add your API keys:
ANTHROPIC_API_KEY=your-key-here
OPENROUTER_API_KEY=your-key-here
TMDB_API_KEY=your-key-here
```

**5. Initialize Database**
```bash
python db.py
```

**6. Generate ML Model (Optional - Pre-built included)**
```bash
python model.py
# or faster version without poster fetching:
python model_clean.py
```

**7. Run the Application**
```bash
streamlit run app.py
```

The app will open at `http://localhost:8501`

## 🗄️ Database Schema

### Users Table
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT UNIQUE,
    email TEXT UNIQUE,
    password TEXT              -- bcrypt hashed
);
```

### Movies Table
```sql
CREATE TABLE movies (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    movie_id INTEGER,
    title TEXT UNIQUE,
    tags TEXT,                 -- Concatenated genres, cast, keywords
    poster_url TEXT            -- URL to movie poster
);
```

### Watchlist Table
```sql
CREATE TABLE watchlist (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    movie_id INTEGER,
    UNIQUE(user_id, movie_id),
    FOREIGN KEY(user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY(movie_id) REFERENCES movies(id) ON DELETE CASCADE
);
```

## 🤖 ML Recommendation Model

### Algorithm: Content-Based Filtering
Uses **cosine similarity** between movie feature vectors to find similar movies.

### Data Pipeline
```
1. Load Data
   ↓
2. Merge Datasets (movies + credits)
   ↓
3. Feature Extraction (genres, cast, keywords, director, overview)
   ↓
4. Text Preprocessing (lowercase, remove spaces, tokenize)
   ↓
5. Stemming (Porter Stemmer normalization)
   ↓
6. Vectorization (CountVectorizer: 5000 features)
   ↓
7. Similarity Matrix (4,803 × 4,803 cosine similarity)
   ↓
8. Recommendations (Top-5 similar movies)
```

### Features Used
- **Overview**: Plot summary
- **Genres**: Movie categories
- **Keywords**: Content tags
- **Cast**: Top 3 actors
- **Crew**: Movie director
- **Movie ID**: TMDB identifier

### Recommendation Algorithm
```python
def recommend(movie_title):
    # 1. Find movie index in database
    index = movies[movies['title'] == movie_title].index[0]
    
    # 2. Get similarity scores for all movies
    distances = similarity[index]
    
    # 3. Sort and return top-5 similar movies
    top_5 = sorted(enumerate(distances), key=lambda x: x[1], reverse=True)[1:6]
    return [movies.iloc[i[0]].title for i in top_5]
```

### Performance Metrics
- **Movies**: 4,803 films
- **Features**: 5,000 vectorized
- **Similarity Matrix Size**: 176 MB
- **Recommendation Time**: < 100ms
- **Accuracy**: Content-based (100% coverage)

## 🔐 Security Implementation

### Password Security
- **Algorithm**: bcrypt with salt
- **Implementation**: `bcrypt.hashpw()` for hashing
- **Verification**: `bcrypt.checkpw()` for login
- **Never**: Stored in plaintext

### Database Security
- **Foreign Keys**: CASCADE delete for integrity
- **SQL Injection**: Parameterized queries throughout
- **Type Validation**: Input sanitization
- **Unique Constraints**: Prevent duplicates

### API Security
- **API Keys**: Stored in `.env` (never in code)
- **Environment Variables**: `os.getenv()` usage
- **Git Ignore**: `.env` excluded from repo
- **HTTPS**: Used for all API calls

```
✓ Ensure write access
```

### Issue: "Movie not found for recommendation"

```

✓ Check key format is correct
```

## 🔄 Model Rebuilding

### When to Rebuild
- After updating movie data
- Changing feature engineering
- Optimizing similarity calculations
- Adding new movie sources

### Rebuild Process
```bash
# Full rebuild with posters (slower, ~10 minutes)
python model.py

# Lightweight rebuild (faster, ~3 minutes)
python model_clean.py
```

### What Rebuilding Does
1. Reads CSV files (movies & credits)
2. Merges on movie title
3. Extracts features (genres, cast, director)
4. Applies stemming normalization
5. Vectorizes text with CountVectorizer
6. Computes cosine similarities
7. Saves similarity.pkl (176 MB)
8. Populates SQLite database
